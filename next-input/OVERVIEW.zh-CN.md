# 下一句建议

客户端打开会话、挂载已完成回答后的建议行时，才根据上下文预测一句用户接下来可能输入的话。没人打开的会话不调用预测模型。建议完整显示，长句自动换行；点击右侧纸飞机直接发送，点击文字可原地编辑后发送或复制回原输入框。建议采用浅色小字，无卡片边框或背景。无法合理预测时不显示建议。

含命令、路径、链接、密钥类词或删除、推送、部署等操作的建议需要先修改文字再发送，不显示一键发送图标。规则采用保守匹配，包含这些词的正常提问也会命中，并不构成完整的安全判断。

需要 Paseo 0.13 或更高版本，以及 daemon 主机上已登录的 Claude CLI 或 Codex CLI。设置中的「预测工具」默认「跟随会话」：Codex 会话用 Codex 预测，其他会话用 Claude，首选的没装时改用另一个；也可以固定为 Claude 或 Codex，固定的工具没装时不预测。Claude 可选 Haiku（默认）、Sonnet、Opus 或自定义模型 ID；Codex 模型留空时用 Codex 的默认模型，推理强度固定为 low。Codex 每次都在一个临时的 CODEX_HOME 里运行：只复制登录凭据（auth.json）和配置中决定请求发往何处的几项（model_provider、[model_providers.*]、chatgpt_base_url 等），配置关闭命令执行、代码模式、看图、浏览器与电脑操作、应用和插件、技能、hooks、记忆、联网搜索，不加载你的 MCP 服务器、插件和 AGENTS.md，在空目录中以只读沙盒运行，结束后删除；若运行中刷新了登录令牌，会在你的凭据未被改动时写回，避免登出。一次只运行一个 Codex 预测。已知限制：当前 Codex 版本无法关闭派生子代理，子代理共用同一份隔离配置，同样没有工具；登录凭据保存在系统钥匙串（cli_auth_credentials_store = "keyring"）时无法用于预测，请改用 Claude。两者都沿用现有账户、服务地址与代理，消耗该账户用量。Claude 先查找 PATH，再依次查找 ~/.local/bin/claude、~/.claude/local/claude、/opt/homebrew/bin/claude、/usr/local/bin/claude；Codex 先查找 PATH，再查找 ~/.local/bin、~/.npm-global/bin、~/.bun/bin、/opt/homebrew/bin、/usr/local/bin 下的 codex。找不到可用的可执行文件时，对话里不显示任何建议行；设置页显示两者的状态、已查找的位置，并支持重新检查。

回答结束约 3.5 秒后才插入占位行，使其通常位于生成速度行之后。同一轮多端打开共用一次预测请求及缓存结果，同时打开也不会重复调用。Claude 请求 30 秒超时，Codex 请求 45 秒超时，不自动重试。新回合会取消上一轮预测，使旧建议失效。子代理回合、失败或取消的回合不预测。客户端没有后台轮询。只要建议行仍挂载，应用被其他窗口遮住时也可能生成，这不是操作系统层面的前台检测。

每次读取当前会话最近最多 8 条用户消息和模型回答，总计不超过 12,000 字符。不发送工具结果、思考过程或附件文件；可见消息中包含的私人文字仍会发送至当前使用的 Claude 或 Codex 服务。Claude 预测进程禁用工具、MCP、技能、自定义 hooks 和思考，不持久化会话；Codex 预测关闭命令与代码执行，不加载你的 MCP、插件和 hooks，使用低推理强度，但仍可能发现全局技能、保留部分辅助工具（见上文已知限制）。两者都不执行任务，不创建 Paseo 子代理。预测提示词使用英文，要求输出符合用户语言和口吻的一句话。建议作为时间线组件显示，保存与恢复由 Paseo 管理；只有点击发送后才会作为用户消息交给主模型。插件不记录对话正文或模型原始响应。

可在设置中关闭自动预测。修改设置会取消正在进行的预测，新设置从下一次完成的回答生效。预测失败显示暂不可用，不用固定建议兜底。界面默认英文，App 语言为简体中文时显示中文。建议随对话滚动；Paseo 未公开原输入框草稿 API，因此不自动填入原输入框，也不提供按 Tab 接受建议的功能。
