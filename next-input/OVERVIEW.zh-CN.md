# 下一句建议

每轮回答结束后，在最近回答下方显示一条完整建议，长句自动换行。右侧向上箭头直接发送这条建议；点击文字可原地展开编辑区域，修改后发送，或者复制回原来的输入框。没有合适的建议时不显示。

需要 Paseo 0.13 或以上，以及 daemon 机器上已登录、可执行的 Claude CLI。使用 Haiku，沿用现有账户、服务地址和代理，消耗该账户用量。每轮正常结束最多调用一次，30 秒超时不重试；开始新回合时取消旧预测。不预测子代理回合。

每次最多读取当前对话最近 8 条用户消息和模型回答，总计最多 12,000 字符。不会读取或发送工具结果、思考过程和附件文件。可见消息中包含的私人文字仍会发送到你配置的 Claude 服务。预测进程禁用工具、MCP、技能与自定义 hooks，不执行任务，也不创建 Paseo 子会话。建议通过时间线组件展示，保存与恢复由 Paseo 管理；按下发送前不会作为用户消息发给主模型。插件不记录对话或原始响应日志。

设置中可以关闭自动预测。请求失败会显示“输入建议暂不可用”，不会用固定话术代替。Paseo 暂无公开的原生草稿写入接口，因此不支持直接填入原输入框或 Tab 接受。建议随聊天记录滚动，不固定悬浮在原生输入框上方。界面默认英文，简体中文界面显示中文。
