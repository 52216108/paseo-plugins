# 下一句建议

客户端打开会话、挂载已完成回答后的建议行时，才根据上下文预测一句用户接下来可能输入的话。没人打开的会话不调用预测模型。建议完整显示，长句自动换行；点击右侧纸飞机直接发送，点击文字可原地编辑后发送或复制回原输入框。建议采用浅色小字，无卡片边框或背景。无法合理预测时不显示建议。

需要 Paseo 0.13 或更高版本，以及 daemon 主机上已登录的 Claude CLI。设置中可选 Haiku（默认）、Sonnet、Opus 或自定义 Claude 模型 ID，沿用现有账户、服务地址与代理，消耗该账户用量。先查找 PATH，再依次查找 ~/.local/bin/claude、~/.claude/local/claude、/opt/homebrew/bin/claude、/usr/local/bin/claude。找不到可执行文件时，对话里不显示任何建议行；设置页显示缺失状态、已查找的位置，并支持重新检查。

回答结束约 3.5 秒后才插入占位行，使其通常位于生成速度行之后。同一轮多端打开共用一次预测请求及缓存结果，同时打开也不会重复调用。请求 30 秒超时，不自动重试。新回合会取消上一轮预测，使旧建议失效。子代理回合、失败或取消的回合不预测。客户端没有后台轮询。只要建议行仍挂载，应用被其他窗口遮住时也可能生成，这不是操作系统层面的前台检测。

每次读取当前会话最近最多 8 条用户消息和模型回答，总计不超过 12,000 字符。不发送工具结果、思考过程或附件文件；可见消息中包含的私人文字仍会发送至当前配置的 Claude 服务。预测进程禁用工具、MCP、技能、自定义 hooks 和思考，不执行任务，不创建 Paseo 子代理或持久化 Claude 会话。预测提示词使用英文，要求输出符合用户语言和口吻的一句话。建议作为时间线组件显示，保存与恢复由 Paseo 管理；只有点击发送后才会作为用户消息交给主模型。插件不记录对话正文或模型原始响应。

可在设置中关闭自动预测。修改设置会取消正在进行的预测，新设置从下一次完成的回答生效。预测失败显示暂不可用，不用固定建议兜底。界面默认英文，App 语言为简体中文时显示中文。建议随对话滚动；Paseo 未公开原输入框草稿 API，因此不自动填入原输入框，也不提供按 Tab 接受建议的功能。
