# Next message suggestion

Shows one context-aware next message below a completed reply when a client opens that conversation and mounts its suggestion row. Unopened conversations do not call the prediction model. The full sentence wraps when needed. Click the paper plane to send directly, or click the text to edit in place before sending or copying it into the main input. Suggestions use small, muted text without a card border or background. When there is no useful prediction, nothing is shown.

Requires Paseo 0.13 or later and a signed-in Claude CLI on the daemon host. Choose Haiku (the default), Sonnet, Opus or a custom Claude model ID in settings. Uses the existing Claude account, endpoint and proxy and consumes that account's usage. The plugin searches PATH, then ~/.local/bin/claude, ~/.claude/local/claude, /opt/homebrew/bin/claude and /usr/local/bin/claude. If no executable is found, no suggestion appears in the conversation. Settings shows the missing CLI status and searched locations, with an option to check again.

The placeholder is appended about 3.5 seconds after a reply ends, to follow the generation-speed row when available. Each eligible turn shares one prediction request and cached result across clients, including simultaneous opens. Requests time out after 30 seconds and do not retry automatically. A new turn cancels the previous prediction and invalidates its suggestion. Subagent turns and failed or cancelled turns are excluded. The client does not poll in the background. A mounted row can trigger prediction even if the app is behind another window; this is not an operating-system foreground check.

Each request reads up to eight recent user messages and assistant replies from the current conversation, capped at 12,000 characters. Tool results, reasoning and attachment files are excluded. Private text contained in visible messages is still sent to the configured Claude service. Prediction disables tools, MCP, skills, custom hooks and thinking, does not perform tasks, and does not create Paseo subagents or persistent Claude sessions. The prediction instructions are in English and ask for a sentence in the user's language and voice. Suggestions are displayed as timeline components, whose storage and restoration are managed by Paseo. They are not sent to the main model as user messages until you press Send. Conversation text and raw model responses are not logged by this plugin.

Automatic prediction can be disabled in settings. Changing settings cancels pending predictions; the new settings apply after the next completed reply. A failed prediction shows an unavailable message instead of a fixed suggestion. The interface defaults to English and follows the app's Simplified Chinese locale. Suggestions scroll with the conversation. Paseo does not expose a public composer draft API, so this plugin does not fill the original input or provide Tab-to-accept completion.
